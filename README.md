# 片思いフォロー整理

Xで、フォローを返していないユーザーの候補を見つけやすくする、Firefox・Violentmonkey向けスクリプトです。フォロー解除は自分で判断して操作できます。

## できること

- 相互フォローの行を隠す／表示する
- 「フォローされています」の表示がない、フォロー中のユーザーを黄色で強調する
- 現在読み込まれている候補と相互フォローの人数を表示する

追加読み込みにも対応します。スクロール位置がずれにくいよう、隠した行の空白は残ります。

## インストール

1. Firefoxに[Violentmonkey](https://violentmonkey.github.io/)をインストールします。
2. [スクリプト](x-follow-helper.user.js)を開き、内容をすべてコピーします。
3. Violentmonkeyで新規スクリプトを作り、初期コードをコピーした内容で置き換えます。
4. 次の行の `CHANGE_ME` を、ログイン中の自分のXのID（@なし）に変更して保存します。

   ```javascript
   const TARGET_ACCOUNT = 'CHANGE_ME';
   ```

5. 自分の「フォロー中」ページを開き直します。右上に操作パネルが表示されます。

## 使い方

黄色の候補を確認し、解除したい場合はXの「フォロー中」ボタンから操作してください。「相互フォローも表示する」で隠した行を戻せます。

停止するにはViolentmonkeyでスクリプトを無効にして、ページを再読み込みします。

## 注意点

- 黄色は非相互フォローの候補です。読み込み途中やXの画面仕様の変更により、判定が正しくない場合があります。
- 件数は現在読み込まれている行だけで、全フォロー数ではありません。
- フォローした日付・期間は判定しません。並び順はXの表示のままです。
- フォロー解除を自動で行う機能はありません。

## プライバシー

このスクリプトは、画面上の表示を読み取って見た目を変更します。独自の外部通信や、アカウント情報の収集・保存は行いません。

設定済みのコードを他の人に共有するときは、IDを `CHANGE_ME` に戻してください。
